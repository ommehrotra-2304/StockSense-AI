# Roadmap

## Phase 1 — Working MVP

- Run the synthetic data generator.
- Inspect CSVs.
- Run EDA notebook.
- Run model training.
- Review metrics and feature importance.
- Generate recommendations.
- Open the Streamlit dashboard.

## Phase 2 — Portfolio upgrade

- Replace/augment synthetic data with a public retail dataset.
- Add holiday and promotion features.
- Compare Random Forest vs Gradient Boosting.
- Add category/store filtering.
- Add model prediction error chart.
- Add screenshots to README.

## Phase 3 — Production-style upgrade

- FastAPI endpoint for forecasts.
- PostgreSQL instead of SQLite.
- Docker.
- Scheduled retraining.
- Model versioning.
- Prediction intervals.
